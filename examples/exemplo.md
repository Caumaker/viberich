# Exemplo do replica
Exemplo: cartões, opções de marcar e navegação por teclado.

## Decisões

### T1: escolha única
- ( ) A: primeira opção
- (*) B (recomendada): segunda opção
- ( ) C: terceira opção

### T2: várias
- [ ] escova
- [x] raspador
- [ ] vibrador no funil

### T3: liga e desliga
- {on} sensor de comporta fechada
- {off} vibrador de cima

Parágrafo normal depois das perguntas, com duas linhas
de texto para testar o retorno do cursor.
